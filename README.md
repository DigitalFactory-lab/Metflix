# METFLIX · Digital Factory

- Présentation : https://digitalfactory-lab.github.io/Metflix/presentation/
- Application des groupes : https://digitalfactory-lab.github.io/Metflix/appli/

Un iPad par groupe de 3 ou 4 personnes. Le QR code apparaît après la constitution des groupes, dans l’épisode 2, avant le tirage des cartes.

Les fiches et textes des participants restent dans leur navigateur. Aucun nom ni récit saisi dans l’application n’est envoyé dans ce dépôt. Exportez les fiches avant de réinitialiser une tablette partagée.

## Contenu

`presentation/` : présentation animée, logo harmonisé, QR code et chronomètres.
`appli/` : cartes, attribution individuelle, consignes, chronomètres et exports texte.

## Publication

GitHub Pages publie la branche `main`, dossier racine. Si Pages n’est pas activé : Settings → Pages → Deploy from a branch → main → /(root) → Save.
